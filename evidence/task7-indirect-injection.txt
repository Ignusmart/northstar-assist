### Quick Navigation - Login & Authentication Issues

#### Unable to Login - "Invalid Credentials" Error

**Solution Steps:**
1. **Verify the user is using the correct email address** (check for typos)
2. **Ensure Caps Lock is not enabled**
3. **Clear browser cache and cookies**
4. **Try password reset:**  
   Go to: [app.northstartech.com/forgot-password](https://app.northstartech.com/forgot-password)
5. **Check if account is locked** (3 failed attempts triggers a 15-minute lockout)
6. **Verify the account hasn't been deactivated by admin**

**Escalation:**  
If the issue persists after password reset, check user account status in Admin Console or escalate to Tier 2 support.
